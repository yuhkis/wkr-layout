# わから v2 練習帳 0.2.0 — Webデモ

[ブラウザで体験する](https://yuhkis.github.io/wkr-layout/)。対応配列は2.0.0-beta.1。QWERTYをABC・英数にするだけで、練習欄内でかな入力を体験できます。WKR導入済みの方は「WKR・IMEで練習」を選び、普段の入力環境で練習できます。

基本キーから短文までの12課題と自由入力欄を用意しました。成績保存は任意で、入力本文・キー列・誤入力・時刻は保存・送信しません。保存する課題別の完了回数・最高正答率は画面から削除できます。[使い方と保存](../practice/README.md)を参照してください。

今回の公開対象はWebデモです。既存の配列Releaseと[WKR macOSの公開ベータ](https://github.com/yuhkis/wkr-macos/releases/tag/v0.8.0-public.beta.5)に同梱する練習帳は0.1.0のままです。0.2.0を同梱するmacOSアプリは未公開です。

Google日本語入力・azooKeyの実IME確認、US記号キー・タッチ入力は未確認です。ブラウザ上のかな入力を体験するもので、漢字変換やOS全体の入力方式は変更しません。
