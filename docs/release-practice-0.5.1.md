# Release情報 — わから v2 練習帳 0.5.1（公開候補）

対応配列は2.0.0-beta.5です。公開済みの配列タグ・仕様ZIP、練習帳0.5.0の添付、Webデモは変更していません。この版の公開操作は未実施です。

IMEで確定したあと、余分なEnterが必要になる場合に備えて採点操作を改善します。確定用Enterのキー識別とkeyupがcompositionendの前後に来る順序を処理し、Enter・NumpadEnter・legacy keyCode 13に対応する識別を追加しました。keyCode 229だけの識別不能なイベントで確定後の保留を解除しません。入力途中・確定Enter・キーリピート・二重操作で採点しないことを合成イベントで検査します。

明示的な「採点」ボタンを追加しました。IMEでひらがなを確定したあと、Enterが反応しない場合に使用できます。QWERTY体験ではEnterと同じページ内変換・採点を行います。入力途中と回答完了後は押せません。

171規則、11課題120問、教材のかな・綴りは0.5.0と同じです。保存は既定オフで、明示的に有効にした場合だけ配列版・課題ID・完了回数・最高正答率を端末内に保存します。入力本文・誤入力・キー列・時刻は保存・送信しません。確定キーの状態はメモリ内だけで、保存やmacOSとの連携へ渡しません。0.5.0と同じ配列版の成績集計を読みます。

合成DOMのイベント順序試験とローカルのChromiumでの操作を、実IMEの入力確認とは区別します。確定キーの識別や離れが欠ける順序、確定直前のcompositionupdateなどは保守的にEnter採点を保留し、確定後のボタン操作を利用します。すべてのIMEで同じEnter回数になることは保証しません。実IME・WKWebViewでのこの版の確認範囲は[検証記録](verification.md)を参照してください。

配布候補は既存の `python3 scripts/package.py` で作る `wakara-practice-0.5.1.zip` です。配列2.0.0-beta.5の仕様ZIPは再生成しません。公開前に全履歴・GitHub上の表面・最終ZIP・サイト・Release本文の監査と操作承認を揃えます。
